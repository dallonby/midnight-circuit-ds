# Midnight Circuit

An original arcade city-driving game for Nintendo DS. Drive through a neon city, collect packages, beat the delivery clock, dodge traffic and pursuing police, earn cash, and repair or upgrade your car at the central garage. The top screen shows the 3D city; the touch screen has a live map and dashboard. The camera follows your car from above, with nearby buildings cut away only when they block its sightline. Cars have solid collision bodies. Your car can nudge traffic and police aside when it has momentum, with brief lighter damage on impact. Police pursue along roads and turn at junctions.

## Play

Copy `midnight-circuit.nds` to an `ROMS/nds` folder on a DS flashcart and select **Midnight Circuit** in its menu. This build is also playable directly in melonDS. No commercial game files or Rockstar assets are needed.

| Control | Action |
| --- | --- |
| D-pad up | Accelerate; start or restart a run |
| D-pad down | Brake and reverse |
| D-pad left/right | Steer |
| A/B | Alternate accelerate/brake controls |
| L | Nitro boost |
| X | At the central garage, spend $100 to repair and change car |
| Start | Pause or resume |
| Select | Toggle the soundtrack |
| Touch and hold a map location | Drive toward that location |
| Touch and hold **L BOOST** | Nitro boost |

The orange map marker is a pickup. Once collected, the cyan marker is the delivery point. Each leg has its own timer. The green center marker is the garage. Completing runs earns cash and unlocks more cars. The game currently starts a fresh run each time it is launched; scores are not saved.

If two police cars box you in and you cannot make meaningful progress for about 1.5 seconds, a **BOXED IN** warning counts down to a **BUSTED** game over. Driving clear resets the warning. Ordinary bumps still let you push a patrol car aside when there is room.

## Soundtrack

The 33-second 1980s-style synthwave loop is original and generated by `tools/generate_music.py`. It is embedded in the ROM as 16 kHz, mono, 16-bit PCM. `soundtrack-preview.wav` is a desktop preview. The old repeated beeps, engine tone, and siren have been removed; game events appear as brief dashboard messages. Press **Select** to switch the music off or on.

To regenerate the audio, run `python3 tools/generate_music.py` with NumPy installed, then rebuild the game.

## Build

Requires devkitPro's devkitARM and libnds. From this folder, run `make -j4`. The output is `midnight-circuit.nds`, now packaged with a DS-only header for legacy flashcart launchers. `tools/generate_icon.py` can regenerate the custom 32×32 cartridge icon as `icon.bmp`.

The game and its soundtrack were created for this project. `source/font8.h` derives from the `font6x8.png` asset in [devkitPro nds-hb-menu](https://github.com/devkitPro/nds-hb-menu), via the Aurora menu in the sibling `ds-aurora` directory. The game source is distributed under GPL-2.0-or-later; see `COPYING`. devkitPro and libnds are separate projects with their own licenses.

## Test status

Built with devkitARM and run in melonDS 1.1 at 60 FPS. Driving, package pickup, delivery, map touch driving, camera tracking, solid vehicle collisions, nudging police cars, and a police chase around the road grid were exercised in the emulator. A separate test ROM put two police cars around the player and blocked a push with traffic; it showed the warning and **BUSTED** screen. Driving away from the same setup stayed playable. The music build ran directly in melonDS, and Aurora launched the game to its title screen in an isolated DLDI SD image. The current build was filmed running on a physical DS, including driving from a pickup toward a delivery. D-pad up/down controls are implemented in the source; a dedicated physical-button test is still pending.
